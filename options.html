Linkding Connection Settings

To connect the extension to your Linkding account, please provide your server's URL and an API token. This is a secure way to grant access without sharing your password.

You can create and find your API token in your Linkding instance under Settings → Integrations.

Chrome Bookmarks Bar Sync

Create a folder on your bookmarks bar that mirrors your Linkding bookmarks. Clicking the button will remove the previous sync folder and create a new one.

Bookmark List UI Settings

Customize the bookmark list to show or hide advanced features for a cleaner look.
